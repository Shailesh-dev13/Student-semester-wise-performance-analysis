# Student Semester -Wise Performance analysis
This project analyses the academic performance of the students across multiple semester using python.it focuses on understanding performance trends,semester-wise averages and individual student progress through data analysis and visualization.

 # Features
 - semester-wise average performance tracking
 - student - wise performance tracking 
 - performance growth percentage calculation 
 - Line chart and histogram visualization
 - downlodable CSV performance report
 - Interactive dashboard using streamlit.

# Dataset
- Type: Synthetic/Mock Dataset
- Records: 1500+ students
- Fields:
 - Student_ID
 -Sem1(semester 1 Marks )
 -Sem2(semester 2 Marks )
 -Sem3(semester 3 Marks )
 
# Technologies used
 - Python
 - Pandas
 - Numpy
 - matplotlib
 - Streamlit

# How to run the project
1.Clone or Download the repositry
2.Install required libraries from requirement.txt
3.Run the streamlit application.

# Conclusion 
This project demonstrate how python - based data analysis tools can be used to gain meaningful insights into student academic performance.It provides a strong foundation in data handling, visualization,and interactive application development.
